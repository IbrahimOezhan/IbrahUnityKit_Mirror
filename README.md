# IbrahUnityKit

## For Github Users

If you are reading this on github, please keep in mind that this is only a mirror since OpenUPM does not support gitlab. The source repo is on [gitlab](https://gitlab.com/ibrahim_oezhan/IbrahUnityKit). If you want to create a pull/merge request, please do it on gitlab.

## Important Dependency Information: 

This toolkit depends on the Odin Inspector which for obvious reasons is **not** shipped with this repo. For more information check https://wiki.ibrahimoezhan.com/Ibrah-Unity-Kit#dependencies

##### Second Option: UPM Git URL

Open the default Package Manager and click on the + in the upper left corner. Select "Install package with git URL" and paste the following URL:

```https://gitlab.com/ibrahim_oezhan/IbrahUnityKit.git#main```

##### Third Option: Git Clone

Simply clone the repository and put it into your project or add it as a submodule

```
git submodule add https://gitlab.com/ibrahim_oezhan/IbrahUnityKit.git
git submodule update --init
```
